# Task 1: Digital Literacy Infographic Report

In today’s digital world, understanding technology is essential for students. To explain this, I created an infographic using **Canva**, a free online design tool with ready-made templates, icons, and layouts. The infographic presents key aspects of **digital literacy** in a simple and visually appealing way.

It focuses on three main topics. First, digital literacy is defined as the ability to use digital devices, online platforms, and the internet responsibly and efficiently. Second, it lists useful digital tools for students, including **Google Docs, Zoom, GitHub, and Canva**, which help with learning, communication, and project work. Third, it highlights safe internet practices, such as creating strong passwords, avoiding suspicious links, and protecting personal information online.

While designing the infographic, I found arranging icons, text, and colors in a clear layout interesting. Initially, selecting the right layout was challenging, but Canva’s templates made it easier.

Overall, this task improved my understanding of digital literacy and visual presentation.
